## VAPID Keys Setup (required after deploy)

1. Run in Cursor terminal:

   ```bash
   npx web-push generate-vapid-keys
   ```

2. Copy the output (Public Key and Private Key).

3. Add to **Vercel → Project → Settings → Environment Variables**:

   | Variable | Value |
   |----------|--------|
   | `VAPID_PUBLIC_KEY` | Public key from step 1 |
   | `VAPID_PRIVATE_KEY` | Private key from step 1 |
   | `VAPID_EMAIL` | `mailto:your-email@gmail.com` |

4. Ensure these are also set (existing):

   - `CRON_SECRET` — Vercel cron auth header
   - `ANTHROPIC_API_KEY` — Claude message generation
   - `SUPABASE_SERVICE_ROLE_KEY` — load users/prefs in cron

5. **Redeploy** from the Vercel dashboard after adding keys.

## Notification Types

| Type | Cron | Time gate |
|------|------|-----------|
| `morning_motivation` | Hourly | User `notification_morning_time` |
| `workout_reminder` | Hourly | Fixed 08:00 user local (toggle only in UI) |
| `midday_checkin` | Hourly | User `notification_midday_time`; skips if food logged |
| `evening_recap` | Hourly | User `notification_evening_time`; uses macro % |
| `streak_celebration` | Daily 20:00 UTC | Streak ≥ 2 weeks |
| `meal_plan_rotation` | Daily 08:00 UTC | Requires `meal_plan_needs_rotation=true` |

All message **body** text is generated by Claude (`claude-sonnet-4-6`, max 60 tokens) using the user's `chosen_coach_id` persona, name, and goal/context. No hardcoded coach messages.

## Known Gaps / Notes

1. **Service worker registration** is production-only (`ServiceWorkerRegister.tsx`). Local push testing requires `npm run build && npm run start` or production deploy.
2. **Workout reminder** has no user time picker in spec; server uses 08:00 in user timezone.
3. **Streak / meal rotation** crons use fixed UTC hours; not per-user time.
4. Disabling notifications in Settings clears `push_subscription` but does not call `subscription.unsubscribe()` in the browser.
5. Vercel cron calls use GET with `?type=`; auth via `x-cron-secret` or `Authorization: Bearer`.
